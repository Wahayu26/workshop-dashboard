# BengkelKu - Modern Workshop Management System (Mobil & Motor)

Sistem Manajemen Bengkel Servis Mobil dan Motor terintegrasi, siap produksi dengan arsitektur Monorepo, Next.js 14, NestJS, Prisma ORM, PostgreSQL, dan Redis.

## 🚀 Tech Stack

- **Frontend**: Next.js 14+ (App Router), TypeScript, Tailwind CSS, shadcn/ui, Framer Motion, Lucide Icons, Recharts, TanStack Query.
- **Backend**: NestJS 10, Prisma ORM, PostgreSQL, Redis, BullMQ, Argon2, JWT (HttpOnly Cookie), Swagger / OpenAPI.
- **Shared**: Type definitions, DTOs, Zod validation schemas.

## 📁 Struktur Monorepo

- `apps/web`: Frontend Next.js 14
- `apps/api`: Backend NestJS API
- `packages/shared`: Shared types, enums, and schemas
